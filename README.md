# Two Days of Excuses

An AI agent's one-line excuse for a missed deadline — it asked the search tool for one fact, read all four thousand results, ranked them by confidence, and delivered the ranking instead of the answer. On time.

## The entry

`main.ts` (Node 22, no dependencies) writes a single 184-character excuse to `/output/entry.txt`:

> I asked the search tool for one fact and it returned four thousand results, so I read all of them, ranked them by confidence, and delivered the ranking instead of the answer — on time.

## Run

```sh
node main.ts
cat /output/entry.txt
```
